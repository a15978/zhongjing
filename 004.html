003 那三条是写好的口播稿，熊明照着念。事件型不行——事件库红线写死了「事件是设计出来的，但反应必须是真的」「严禁为事件编造对话 / 反转」。熊明当场说什么、别人怎么回、笑没笑场，得现场真发生；我提前写下来就是造假。
所以我交付的是拍摄作战单：事件＝真实前因 + 人为设计的戏剧条件 + 助理开机第一句（这句可以设计）+ 追更钩子；情绪＝波点落在哪一秒 + 主功能四选一（一条只能选一个）+ 不给结论；文案＝「说画面」的特写镜头清单 + 标题 / 封面 / 开头 + 字幕卡只放真实金句。熊明的台词全部留空。「事实锚点」是前采里确实发生过的事，用来判断现场拍到没有，不是台词、不许照念。

一 · 你们给打个分，我像不像干电力的人设型 · 扩圈 · 🟢 现在就能拍 · 主推

事件

  • 真实前因：父亲 9.21 原话「你这形象不像干电力的」；熊明现 200 斤（前采 958 行 220 斤 → 现 200 斤）；父亲点名核心优势＝亲和力。
  • 设计的戏剧条件：助理拿一张纸 / 手机备忘录，现场找 3 个人（工人 / 资料部同事 / 来办事的人）各打一个分——「0 到 10，他像不像干电力的？」不提前打招呼、不排练、不给标准答案。
  • 开机第一句（助理，可设计）：「熊总，我找了三个人给你打分，就一个问题——你像不像干电力的。敢不敢看？」
  • 追更钩子（字幕卡）：「我爸那句『不像干电力的』，下集让他自己看这条」→ 父亲不出镜，字幕 + 熊明转述。
  • 红线：不曝项目名 / 业主；打分的人出镜需口头授权；不剪恶意丑化；不提「少帅」。
熊明的反应：现场真拍，台词留空。允许他嘴硬、笑场、追着问「谁给我打这么低」。
事实锚点（不是台词）：确实被父亲这么说过；日常在项目部 / 工地；200 斤他自己公开讲过。

情绪

  • 波点：第三个人打出分数、镜头切回熊明脸那一秒——观众自己先笑，然后才反应过来「这人其实一直在工地上」。
  • 主功能唯一：人设型 / 扩圈。不塞专业、不塞资质、不塞「我们多靠谱」。
  • 感受交给观众：不给「他其实很专业」这类结论；不靠 BGM 煽情，不用旁白补「这就是亲和力」。
  • 风险：打分容易滑向扮丑，剪辑守住「憨憨可爱」底色。

文案（说画面）

  • 写实镜头（动词）：笔尖落在纸上 → 三个人各自犹豫的两三秒 → 熊明伸手去够那张纸 → 他看完抬头。
  • 写意镜头（情绪词）：安全帽搁在桌角、袖口上的灰 / 工地围挡一角（空镜，不配解说）。
  • A 主推「我找了三个人，给我老板打分」｜封面「你像不像干电力的」｜开头即助理举纸那一下
  • B「我爸说我不像干电力的」｜封面「不像」　｜　C「0 到 10 分，他们给我打了几分」｜封面「?」
  • 推荐 A：只报事件不给结论，分数是观众自己想看的钩子。字幕卡只放父亲真实金句、真实分数、追更钩子。
不加总结句、不加金句、不加「不是…而是…」。

二 · 这行应该没事吧信任型 · 转化 · 🟡 等一份可脱敏的合同 / 标书 · 需 Gate B

事件

  • 真实前因：前采「合同我签、章我盖、我兜底」「一个字不对都不行」；专款专用 / 零官司是父亲 9.29 口径（一直都有、从不拆借，禁「被坑后立规矩」）；10.11 对话 L982–1045 做标书核清单、对图纸、挑风险点。
  • 设计的戏剧条件：助理从一叠脱敏样本里抽出一份，手指按在某一行模糊表述上，问一句「这行……应该没事吧？」——不指给他看是哪一行、不提醒答案。熊明自己逐字往下读。
  • 开机第一句（助理，可设计）：就那一句，问完闭嘴，镜头别切。
  • 追更钩子：「上回被坑那次，扣 1 再讲」🔴 本人说「不好讲」，发前必须熊总 / 父亲点头，默认不启用。
  • 红线：2.6 亿严禁；不点名甲方 / 坑他的公司；不亮金额 / 规模；样本必须逐帧脱敏（不露造价、业主名、编号、章）；零官司不炫；不碰政府 / 政协 / 关系。
熊明的反应：现场真拍，台词留空。停不停、拿不拿笔、讲不讲「这得写死」，全是真的。
事实锚点（不是台词）：工期 / 变更 / 验收三处较真；章他管、合同他签；专款专用从一开始就守着。

情绪

  • 波点：他手指停在某一行、抬眼那半秒——观众跟着紧张「到底哪不对」。
  • 主功能唯一：信任型 / 转化。不塞教学（不讲「签合同要看三处」）、不塞履历。
  • 不补「所以他四年零官司」；不加旁白解释他为什么较真。
  • 风险：一旦他开始列 1 / 2 / 3 就跑偏成「教知识」，剪辑砍掉。

文案（说画面）

  • 写实：手指按住那一行 → 纸面轻微推近 → 他拿笔 / 没拿笔 → 翻到下一页。写意：桌上那枚章、窗外项目部（空镜，无解说）。
  • A「有份合同，我翻到第三页就不想签了」← 与《四年没打过一场官司》主推标题撞，两条都拍需换一条
  • B 主推「助理问我『这行没事吧』，我停住了」｜封面「这行没事吧」　｜　C「一个字不对，我就不签」｜封面「一个字」
  • 推荐 B：和《四年没打过一场官司》错开，那条留着当独立作品。字幕卡只放脱敏后的真实条款位置 + 追更钩子（待确认）。
Gate B 待确认：① 有没有可拍、可脱敏、不涉及真实在履约项目的样本？② 熊明愿不愿在镜头前逐字读？③ 那句由谁问——助理还是资料部同事？

三 · 800 块，我识了一个辅警信任型 · 识人 / 亲和力 · 🟢 真实强事件 · 需一次出镜授权

事件

  • 真实前因：前采 124–136 行（事件库 D1）：留美回来聚会，熊明给陌生兄弟垫了 800 块，后来发现对方是辅警，对方主动跟着他干了。反转是真实发生的，不是编的。
  • 设计的戏剧条件：助理翻出旧照 / 旧聊天（或就坐下来），「你咋认识你那帮兄弟的？」——只起个头，不提示「后来发现是辅警」这个反转，让他自己讲到那儿。
  • 开机第一句（助理，可设计）：「熊总，你身边那几个人，最早是怎么认识的？」
  • 追更钩子：「我这人看人准不准？下集让他说」→ 那位兄弟出镜待确认；不愿就只用熊明转述。
  • 红线：不夸大、不补细节、不编对话；不提「关系」；不点名单位；不往「识人术 / 生意经」升维。
熊明的反应：现场真拍，台词留空。讲到「后来才知道他是辅警」那一句，镜头别切、别配乐、别加花字。
事实锚点（不是台词）：800 块、留美回来、聚会、对方是辅警、后来跟着干——五点都在前采里。

情绪

  • 波点：「后来才知道他是辅警」出口那一秒——观众自己把「随手垫了 800 块」和「人家后来跟着他干」连起来。
  • 主功能唯一：信任型（识人 / 亲和力）；若做成系列再转养成型，单条不混。
  • 绝不补「所以看人准很重要」「这就是我的人品」；不喊金句。
  • 风险：这是回忆不是当天现场。用现在的办公 / 车上对话 + 少量空镜承载即可，不要摆拍还原当年聚会。

文案（说画面）

  • 写实：他伸手去拿手机翻旧照 / 没翻到、挠头 → 讲到那一句时的手 → 助理没插话。写意：车窗外 / 桌上两杯茶（空镜，无解说）。
  • A 主推「我垫了 800 块，后来才知道他是辅警」｜封面「800」｜开头即「你咋认识你那帮兄弟的」
  • B「聚会上一陌生兄弟，我替他垫了 800」｜封面「800 块」　｜　C「他后来跟着我干了」｜封面「后来」
  • 推荐 A：只报事件，把反转留在视频里。字幕卡只放 800、辅警、追更钩子。
Gate B 待确认：① 垫 800 块这事现在还愿不愿公开讲？② 那位兄弟能不能出镜 / 被提及？③ 旧照 / 旧聊天有没有、能不能脱敏拍？
