中京 · 拍摄方案（GitHub 版）部署说明
==========================================

文件夹里 3 个文件：
  index.html   首页（方案列表）
  001.html     方案一拍摄卡
  002.html     方案二拍摄卡

三个文件必须放在同一层，不要套文件夹。以后每加一个方案，
就多一个 html 文件，同时 index.html 要一起换新的。


第一步：建仓库（只做一次）
------------------------------------------
1. 打开 github.com，登录
2. 右上角 "+" → New repository
3. Repository name 填 zhongjing（全小写，别的名字也行）
4. 选 Public（公开）
5. 点绿色 Create repository


第二步：传文件（只做一次）
------------------------------------------
1. 仓库页面点 "uploading an existing file"
   （或 Add file → Upload files）
2. 把 index.html、001.html、002.html 三个一起拖进去
3. 点绿色 Commit changes
4. 检查：仓库首页能直接看到这 3 个文件，没有多一层文件夹


第三步：开网页（只做一次）
------------------------------------------
1. 仓库顶部 Settings → 左边菜单 Pages
2. Source 选 "Deploy from a branch"
3. Branch 选 main，右边选 / (root)，点 Save
4. 等 1～2 分钟刷新，页面顶部会出现：
   "Your site is live at https://你的用户名.github.io/zhongjing/"
5. 点开就是方案列表，点卡片看拍摄卡


第四步：手机上用
------------------------------------------
把上面那个网址发到微信「文件传输助手」，手机点开收藏即可。
iPhone 可以「添加到主屏幕」，跟 App 一样用。


以后加新方案
------------------------------------------
找编导要两个文件：新的 00X.html + 新的 index.html，
在仓库里 Add file → Upload files 一起拖进去覆盖 → Commit。
1 分钟后手机上就能看到。


注意
------------------------------------------
1. 这个网址任何人都能打开（公开网页），只是搜索引擎不会收录。
   自己用没问题，别往群里发。
2. 改文件后 GitHub 一般 30 秒～2 分钟生效，不用重新设置 Pages。
3. 别删仓库，删了网址就没了。
