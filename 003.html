A · 一张标书，要过多少道手晒过程 / 专业度 / 纯旁白 0 露脸 · 约 50 秒

交到甲方手上的标书，就是这么一本。

可它在装订之前，得过几道手。

头一道，核清单，怕漏项。

第二道对图纸——清单跟图纸，得对得上。

第三道费功夫：把风险点一条条挑出来，哪儿到时候会卡，先摆到桌面上。

资料部和工程部还得坐下来再过一遍，碰上拿不准的，把客户也请来一起对。

都对完了，才轮到盖章、装订、送出去。

少过一道手，省的是我们这边的事；真漏了，还的是工地上一趟返工。

配「资料部」实拍（17 个文件 / 16.2 GB 待挑镜头）：翻标书、核清单、圈图纸、盖章、装订。封面和单据逐帧脱敏。

B · 为什么我们这边的款不拖信用 / 服务 / 露脸 <30 秒 或纯旁白 · 约 45 秒

把工程交出去，钱这一环，谁都不放心。

我一直是这么做的：一个项目的钱，就花在这个项目上，一分不挪、从不拆借。

下游的班组、材料，该结就结，不压着。

专款专用这话，我们不是今天才讲，从一开始就守着。

到日子钱到了，工人安心，队伍就稳。

C · 甲方为什么第二次还找他口碑 / 条件稿 · 事实缺口未补前不定稿 · 约 45 秒

干完一单，怎么判断这活儿到底干得怎么样？

不看验收那天，看甲方下一次还找不找我们。

电送上了，我们的人没走——长期运维、应急抢修，队伍还在。

半夜跳了闸，有人接电话，有人到场。

项目部是省里的示范项目部。

有没有第二次，我不催。活儿摆在那儿，人家自己会算。

⚠️ 这条有事实缺口，先看再定：项目记忆里没有一条经核实的「同一甲方第二次合作 / 转介绍」事实。002 结尾「甲方下一次还找不找你，就是答案」是价值主张，不是已发生的事。按零编造铁律，不能写「某某客户又找了我们」。所以本稿把「第二次」当判断标准讲，不当已发生的事讲；底子只用可核实的：长期运维「送完电不消失」+ 应急抢修队伍（蓝V旁白 Q6）、湖南省示范项目部（10月11日 L527–559）、半夜抢修（置顶文案「夏冬保电抢修」）。

待确认 3 条（这条必须先答）

  1. 有没有一个真实的「同一甲方第二次合作 / 转介绍」例子？不点名、不带金额，只要「有过」这个事实。有 → 这条能做成硬口碑片。
  2. 有没有可拍的锦旗 / 感谢 / 长期运维台账（脱敏）？
  3. 若都没有 → 建议 C 改题成《送完电，人还在不在》讲长期运维，或暂缓 C。
去重警告：「看甲方下一次还找不找我们」与 002 结尾重叠。C 若入选，须改 002 结尾或换 C 的钩子。
